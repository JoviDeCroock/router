# TanStack Preact Start

TanStack Preact Start is a fullstack framework for SSR, streaming, server functions, API routes, and bundling powered by [TanStack Router](https://tanstack.com/router) and Vite.

Visit [tanstack.com/start](https://tanstack.com/start) for docs, guides, API, and more.
